# Credits

## Music（背景音乐）

All tracks shipped in `/music` were collected as royalty-free / "no copyright"
background music from public free-music libraries. Artist names are kept in the
filenames. **Licenses were not re-verified at ship time — if you plan any
commercial use, check each track's license page yourself.**

Every session starts with the theme, then the rest of the pool plays shuffled.
Track titles are never shown in-game (no interruption to the mood).

If you are a rights holder and want a track removed, open an issue — it will be
taken out of the build.

## Inspiration

- **Rich Dad Poor Dad** (Robert T. Kiyosaki) — the asset/liability rule the whole
  economy is built on. The cover carries a dedication.
- **Warren Buffett & Charlie Munger** — quoted in-game and on the news paper's
  dedication line. All quotes are short, attributed, and used as homage.

## Art

100% original and programmatic: the Manhattan grid, every building silhouette,
every character, the skyline, the wheel — all drawn by code at boot. No external
images, no sprites, no logos, no engine. If it looks like something famous,
it is a parody reference drawn from scratch.

## Fonts / tooling

Georgia / Verdana system fonts only. Built and QA'd with Playwright (Edge).
