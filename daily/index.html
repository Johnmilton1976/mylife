DAILY RUN · ONE LIFE A DAY

One city. One seed. One day.

Every player gets the same life today. MY LIFE's daily challenge draws the whole city from one shared seed: the same face on the character sheet, the same four birth corners, the same neighbours, the same market candles and the same events. No save file to lean on, no luck advantage — just how well you read the same city everyone else is walking. Tomorrow the seed rolls over and a new life begins.

Why a daily run plays differently

The normal game is yours: you can reload a saved life, retry a decision and take as long as you like. A daily run strips that away. It never touches your save, it starts from the same sheet for everyone, and it keeps your best net worth for that date in a small local ledger. There is no server and no account — the comparison is with the city, not with a leaderboard.

  • Fair by construction. One seed per date drives every random draw in the run.
  • No save to exploit. A daily run is a throwaway attempt; your normal life stays untouched.
  • Small enough to finish. One sitting, one score: net worth at the end of the run.
  • Replayable. A friend can open the same dated link and walk the identical city.

How to run a day

  1. Open the link above for today's date, or a shared dated link for another day.
  2. Enter a name and start: the cover tells you which date's city you are about to walk.
  3. Spin, walk and make the same kind of decisions you would in a normal life — job, skills, assets, debt.
  4. Read your ending card, copy your score, then come back tomorrow for a fresh seed.

Share one day, not a thousand URLs

Press Copy share link and send it to a friend. The date lives after a # in the address — a browser fragment that never reaches the server and is never indexed as a separate page. The only crawlable address is this one, mylifesim.com/daily/, which is why the challenge can be found by search while each day still has its own shareable address. The game itself keeps a single canonical URL.

Questions people ask

What is the MY LIFE daily run? A life simulator run where every player gets the same random seed for a given calendar day — the same city, neighbours, market candles and events. It is a fair one-day challenge with no save file to hide behind.

How is the daily seed decided? The seed is the local calendar date in YYYYMMDD form. Everyone playing on that date in their own timezone gets the same sequence; the next day brings a new city.

Does a daily run save my progress? No. It never reads or overwrites your normal saved life. Your best net worth for each date is kept locally in your own browser.

Can I replay an earlier day? Yes. A shared link with a date such as #2026-11-20 replays that exact seed, so a friend can run the same day you did.

Is it free? Yes. The entire game is free — no account, no install, no in-game ads and no purchases of any kind.
