# MY LIFE — A Life Simulator on the Streets of New York

一个**单文件**的纽约人生模拟器。转转盘、在曼哈顿街区里走路、找工作、买「把钱放进口袋」的资产、避开「把钱掏出口袋」的负债，试着在身体和心情被城市拖垮之前离开 rat race。

> **游戏规则只有一条（Rich Dad）**：资产每个月把钱放进口袋；负债每个月把钱掏出去。价格标签决定不了任何事，现金流的方向才决定。

整个游戏就是 `index.html` 一个文件——没有安装、没有账号、没有服务器、没有内购。存档只写在你自己的浏览器（localStorage）里，永远不会上传到任何地方。

**在线玩 / How to play**：把仓库部署到 GitHub Pages（Settings → Pages → 选 `main` 分支根目录）即可，或直接双击打开 `index.html`。

---

## 玩什么 · Features

- **一块真正的曼哈顿棋盘**：程序化生成的街道网格、中央公园、百老汇对角线，地标建筑全部原创程序化绘制，白天/黄昏/夜晚的光影会随游戏内时钟流动，还有季节和天气。
- **转盘走格子**：经典 1–6 转盘决定步数，路过建筑可以直接走进去办事——银行、学校、健身房、公司、餐厅、房产中介。
- **26 份工作 × 8 项技能**：每一份技能都有自己的职业阶梯；学费随等级上涨，学习过度会带来压力。
- **真实现金流表**：CASH / BANK / ESTATE 三张面板背后是一张完整的收支表——工资、股息、房租、账单、贷款利息、每月经营损益，全部可查。
- **Wall Street LIVE**：14 只股票与 10 处房产实时报价，K 线图、股息现金流、净值与涨跌一目了然。给你分红的是资产；赌价格的不是。
- **好债 / 坏债**：银行只借两种钱——消费（15% APR）或买「收益率高于 6% APR 的资产」。
- **人生目标 14 级阶梯**：从「找到第一份工作」到「被动收入覆盖全部账单」。全部达成时，会有一张属于你这辈子的总结卡（**A LIFE, LIVED**）。
- **城市排行榜**：每周印刷一次的净产值榜，你和五个邻居同场竞技；连续 3 个月霸榜成就王朝。
- **身体会记账**：连续工作、压力、心情互相牵连；体检单每天结算，崩溃进急诊室是要花钱的。
- **手动存档**：按 dock 上的 💾 立即存档，▶ 或封面 CONTINUE 读回；存档只写在你自己的浏览器里

## 操作 · Controls

| 输入 | 作用 |
|---|---|
| 转盘点击 / `SPACE` | 转盘，走格子 |
| 拖拽 / `WASD` / 方向键 | 平移镜头 |
| 滚轮 / 捏合 | 缩放（拉远 = 城市全景） |
| `O` | 设置 |
| `M` | 音乐开关 |
| `ESC` | 关闭所有面板 |
| 点击时钟 | 调节时间流速（1× / 2× / 4× / 8×） |

手机：直接点转盘、拖地图、双指缩放；刘海屏与 Home 条已做安全区适配。

## 怎么跑 · Run & Deploy

```bash
# 本地：不需要任何构建，直接打开
index.html

# 或起一个静态服务
python -m http.server 8000
# http://localhost:8000
```

部署到 GitHub Pages：仓库根目录已有 `index.html`，到 **Settings → Pages** 选择分支根目录即可。分享链接的预览图是仓库里的 `og-cover.png`（若你的域名固定，建议把 `<meta property="og:image">` 改成绝对地址，抓取更稳定）。

## 设计笔记 · Design notes（为什么要这样设计）

- **压力不是惩罚，是预算。** 持仓越多越要操心——但总量有上限，而且「钱替你付账」本身会减压。自由不是零压力，是不再为账单失眠。
- **每周有一天休息。** 旧版本里打工人 365 天无休，「5 天没休息」的惩罚无限复利；现在休息日真的休息。
- **破产有托底，但不是礼物。** SNAP 食品券每月 +$292；红字超过 $2,000 触发债务重组，清掉负债但没收一半资产基金。
- **每次调参都有账**。所有数值改动都在注释里写明动机和前后数据（见 `tests/`）。

## 测试 · Tests

`tests/` 内是 Playwright 驱动的回归与平衡脚本（模拟真实游戏循环，不用 mock）：

```bash
npm i playwright        # 或使用系统 Edge
node tests/smoke.js     # 冒烟：启动无报错
node tests/balance_test.js   # 五种玩家画像 × 365 天的平衡审计
node tests/verify_cam.js     # 开场拉远镜头只演一次
```
